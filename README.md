# 🔬 Juego "Adivina la Lesión" — Patología Sistémica (Profe Ana Acosta)

Juego de estudio para el parcial de patología sistémica. Te describe una lesión
(macroscópico, microscópico y **qué células hay**) y tú adivinas de qué patología se trata.

## Cómo usarlo

Abre **`juego-adivina-lesion-OFFLINE.html`** con doble clic. Funciona sin internet.
(También está la versión en carpeta: `juego/index.html` + `juego/lesiones.js`.)

## Para qué está diseñado

Entrena las dos cosas que más cuestan en el parcial:

- **Contenido celular microscópico:** agudo = neutrófilos; alérgico/parásito = eosinófilos;
  crónico = macrófagos + linfocitos + plasmáticas; granuloma = + células gigantes.
- **Parejas de confusión:** las opciones falsas son justo las lesiones que se confunden
  (bronconeumonía vs neumonía intersticial, congestión izquierda vs derecha,
  esteatosis vs degeneración hidrópica, glomerulonefritis vs amiloidosis,
  pielonefritis vs nefritis intersticial, endocardiosis vs endocarditis, etc.).
  Al fallar, te muestra la **clave para diferenciarlas**.

Modos: opción múltiple o respuesta abierta. Filtro por sistema o todos mezclados.
Puntaje, racha y pista opcional.
